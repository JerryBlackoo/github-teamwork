## 边界规则

- 前端不直接绕过 Gateway 或 API 聚合层访问内部服务，除非架构决策明确允许。
- 服务之间的共享字段、错误码和权限语义必须写入契约文档。
- 一个模块不应同时拥有数据写入、跨域决策和 UI 展示三种职责，除非有明确理由。
