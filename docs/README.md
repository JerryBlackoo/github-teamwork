# 文档索引

这个目录保存团队协作模板的制度、模板和检查清单。

## 推荐阅读顺序

1. 新人先读 [../README.md](../README.md) 和 [../CONTRIBUTING.md](../CONTRIBUTING.md)。
2. 仓库维护者读 [collaboration/repository-setup.md](collaboration/repository-setup.md)。
3. 任务协调人读 [collaboration/task-issue-project-workflow.md](collaboration/task-issue-project-workflow.md)。
4. 文档维护者读 [collaboration/documentation-workflow.md](collaboration/documentation-workflow.md)。
5. 测试负责人读 [testing/strategy.md](testing/strategy.md)。
6. 使用 AI agent 的人读 [collaboration/agent-workflow.md](collaboration/agent-workflow.md)。

## 目录说明

| 路径 | 用途 |
| --- | --- |
| `docs/collaboration/` | 分支、PR、Issue、Project、文档和 agent 协作规则。 |
| `docs/testing/` | 测试策略、测试证据和测试报告模板。 |
| `docs/architecture/` | 服务边界、能力矩阵等跨组契约模板。 |
| `docs/templates/` | 项目启动、发布等通用清单。 |
